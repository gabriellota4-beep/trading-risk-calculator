# Trading Risk Calculator

A simple web-based trading risk calculator for position sizing and risk management.

## Features
- Calculate risk amount based on account size and risk percentage
- Calculate position size based on stop loss
- Simple and clean interface
- Automated testing using Jest

## Technologies Used
- HTML
- CSS
- JavaScript
- Jest

## How to Use
1. Enter account balance
2. Enter risk percentage
3. Enter stop loss
4. Click calculate

## Testing
Run the following command:
npm test
